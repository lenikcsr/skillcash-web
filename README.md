# SkillCash Web

Aplicación web desarrollada en Java utilizando JSP, Servlets, JDBC y MySQL.

## Tecnologías utilizadas

- Java
- JSP
- Servlets
- Apache Tomcat 10
- Maven
- JDBC
- MySQL
- Bootstrap

## Funcionalidades

- Registro de usuarios
- Consulta de usuarios
- Edición de usuarios
- Eliminación de usuarios
- Conexión con base de datos MySQL

## Estructura del proyecto

- `conexion`: conexión a la base de datos.
- `dao`: operaciones CRUD.
- `modelo`: clases del modelo.
- `servlet`: controladores.
- `webapp`: páginas JSP y recursos.
